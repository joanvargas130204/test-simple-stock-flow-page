Control de Stock y Ventas para Almacén

Diseñado bajo Spec-Driven Development (SDD) y Arquitectura Onion de 4 Anillos en PHP 8.2 (Laravel 11), React 19 y Docker. Garantiza inmutabilidad contable, concurrencia optimista y exactitud monetaria.

Las 3 Afirmaciones Fundamentales

Invariantes innegociables del sistema sobre las cuales descansa toda la lógica de negocio.

🛡️

1. El stock visible es el stock real

Control de concurrencia optimista con versionado atómico y transacciones que impiden sobreventas simultáneas.

🔒

2. Venta registrada es inmutable

Una vez confirmada una venta, los precios, nombres y categorías quedan congelados para siempre.

📊

3. Reportes históricos estables

El reporte de un período cerrado dice hoy lo mismo que dirá dentro de diez años, inmune a cambios del catálogo.

Arquitectura Onion (4 Anillos + Bootstrap)

Aislamiento total del Dominio respecto a Laravel, frameworks y bases de datos.

Presentation (HTTP Controllers, Requests, Formatos RFC 7807)
Application (Casos de Uso, DTOs, Puertos Inbound y Outbound)
Domain (PHP 8.2 Puro, Entidades, Value Objects Money/Quantity)
Infrastructure (Modelos Eloquent, Mappers, Repositorios, JWT, FileStorage) ➔ Bootstrap

Stack Tecnológico

Herramientas modernas elegidas para máxima reproducibilidad, seguridad y rendimiento.
