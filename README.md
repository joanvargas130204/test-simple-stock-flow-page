# Simple Stock Flow — Landing Page de Presentación

Página web estática institucional para la presentación del proyecto formativo **Simple Stock Flow** (Ficha ADSO-3413974).

---

## 📄 Contenido

- **Resumen Ejecutivo:** Explicación funcional del sistema de inventarios y punto de venta.
- **Las 3 Afirmaciones:** Principios de consistencia de stock, inmutabilidad de ventas e integridad histórica de reportes.
- **Arquitectura Onion:** Visualización didáctica de los 4 anillos concéntricos y el contenedor Bootstrap.
- **Stack Tecnológico:** PHP 8.2 (Laravel 11), React 19, MySQL 8.4, Docker.
